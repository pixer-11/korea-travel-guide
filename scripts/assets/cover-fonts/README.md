# Social cover fonts

Used by `scripts/lib/social-cover.mjs` for the Threads/Instagram first slide.
All five are from Google Fonts (github.com/google/fonts, `ofl/`), licensed under
the SIL Open Font License 1.1 — free to bundle and redistribute with this notice.

| File | Family | Used for |
|---|---|---|
| YoungSerif.ttf | Young Serif | soft serif titles |
| Playfair.ttf | Playfair Display (variable, default instance) | didone titles, serif kickers |
| KronaOne.ttf | Krona One | wide titles |
| ArchivoBlack.ttf | Archivo Black | grotesk titles |
| Inter.ttf | Inter (variable, default instance) | small labels and the meta row |
