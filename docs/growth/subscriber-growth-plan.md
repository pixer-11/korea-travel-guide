# 구독자 성장 계획 (2026-07-26)

전제: 무인 운영 원칙 유지, 사장님은 비개발자, 예산 최소. 구독자 = 방문자 수 × 전환율.
현재 병목: 신생 도메인이라 방문자 자체가 적음 → 전환 장치(자동)와 유입 확대(반자동)를 동시에.

## 조사 근거 (2025-26 데이터)
- 이메일 리스트 평균 성장률 4%/년(2024) — 리스트 모으기는 전반적으로 어려워지는 중. 잘 되는 팀은 "여러 개 대충"이 아니라 "한두 개 제대로": 잘 만든 팝업 1개가 어중간한 전술 10개보다 낫다.
- 폼 입력칸 수가 결정적: 이메일 1칸 4.41% > 2칸 2.90% > 3칸 1.93% — 칸 하나 늘 때마다 전환 1/3씩 증발. → 우리 폼은 이메일 1칸 유지.
- 팝업 전환 벤치마크: 일반 이메일 팝업 2-5%, 이탈 감지 3-10%, 클릭 유도형 10%+.
- 리드마그넷: "돈 주고 살 만큼 좋은 것" 하나가 일반 ebook 12개보다 낫다. 짧은 실용 문서/체크리스트류가 전환 상위.
- 소형 뉴스레터 상호홍보(스왑): Lettergrowth(무료)·SparkLoop Upscribe·Refind 1:1 스왑 — 1만 구독 이하 구간에서 특히 효과적. 단, 우리는 실구독자가 두 자릿수가 될 때까지 보류(스왑도 보여줄 게 있어야 성립).
- 경품 이벤트(giveaway)로 부풀린 리스트는 열람률 붕괴 → 배제. 추천(referral)·검색 유입 구독자가 참여도 최고.

## 실행 로드맵

### A. 지금 완료 (자동, 코드)
1. ✅ 사이트 전역 구독 팝업 (NewsletterPopup.astro)
   - 트리거: 스크롤 50% 또는 이탈 직전(데스크톱). 로드 즉시 표시 안 함 → 구글 방해 팝업 벌점 없음.
   - 화면을 덮지 않는 카드형(데스크톱 우하단 / 모바일 하단, 예약바 위).
   - 미끼: 무료 여행 체크리스트(기존 /free/trip-checklist). 이메일 1칸.
   - 빈도: 세션당 1회, 닫으면 14일 숨김, 구독하면 영구 숨김. 5개 언어.
   - 계측: Plausible 'Popup shown' / 'Newsletter signup(via popup)' — 전환율 측정 가능.
2. ✅ 위젯 "최저가 비교" 카피 (전환·신뢰 개선, 88aeffd)

### B. 다음 자동화 후보 (승인되면 코드로)
1. 국가별 리드마그넷 자동 생성 — "○○ 3일 일정 + 체크리스트" PDF를 기존 콘텐츠에서 자동 조립, 해당 국가 페이지의 팝업/CTA에 연결 (전환율 ↑: 페이지 맥락과 일치하는 미끼는 일반 미끼보다 전환 높음).
2. 뉴스레터 아카이브 페이지(/newsletter) — 과거 호를 웹에 공개해 SEO 유입 + "이런 걸 받게 됩니다" 미리보기 → 구독 전환.
3. 글 중간 인라인 구독 박스 A/B — 현재 글당 1곳(중간 체크리스트 CTA)+하단. 위치·문구 실험은 Plausible 데이터 쌓인 뒤.

### C. 사장님 몫 (사람만 할 수 있는 것, 각 5-15분)
1. **Pinterest 토큰 등록** — 자동 핀 파이프라인이 토큰만 기다리는 중(PINTEREST_ACCESS_TOKEN). 여행 유입 2위 채널이 통째로 잠겨 있음. 최우선.
2. **Travelpayouts에서 여행자보험 프로그램 신청** (EKTA 등) — 승인되면 링크만 주시면 위젯에 넣음(고단가 제휴 공백 메움).
3. 지인 초대 — 기존 지인/고객에게 "구독 초대 링크" 개인 발송(재허가 정책과 일치; 대량 임포트 금지).
4. (나중, 실구독자 50+ 시) Lettergrowth 무료 등록 → 스왑 파트너 매칭은 내가 조사·제안.

### D. 하지 않기로 한 것
- 경품 이벤트(리스트 오염), 구독자 구매(계정 정지 위험), 대량 지인 임포트(스팸 신고→발신 평판 붕괴), 과도한 전면 팝업(SEO 벌점).

## 측정
- 주간 마케팅 리뷰(월 20:25 KST 루프)에서: 팝업 노출→구독 전환율(벤치마크 2-5%), 언어별 구독 증가, 발송 열람률.
- 목표: 팝업 전환율 2% 미만이면 미끼/문구 교체, 5% 이상이면 유지하고 유입 확대에 집중.
