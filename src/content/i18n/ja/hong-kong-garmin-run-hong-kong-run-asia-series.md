## 12月の日曜日、吐露港のほとりで

馬鞍山（Ma On Shan）の景色は、絵はがきで見る香港とはまったく違います。吐露港（Tolo Harbour）の西岸には高層マンションがずらりと立ち並び、その背後に馬鞍山の緑の稜線がむき出しのままそびえています。2026年12月20日（日）、この街がGarmin Run Asia Seriesの香港ロードレースの舞台です。距離は3K・10K・21Kの3種目です。

Garmin Run Asia Seriesは、アジア各地の都市を転戦するガーミンのレースシリーズで、この大会はその一戦にあたります。香港大会の会場は、坂が多く交通量も激しい都心部ではなく、平坦な水辺の街です。九龍の歩道を走ろうとしたことがある人なら、この選択のありがたみがよくわかるはずです。

## 3K・10K・21K、どれを選ぶか

3つの距離は、それぞれ向いているランナーが異なります。

- **3K：** 短い距離なので、家族連れや走り始めたばかりの人、本格的な練習なしでメダルを手にしたい人にぴったりです。
- **10K：** 普段から走っている人が、気持ちよくスピードに乗ったタイムを狙う定番の距離です。
- **21K：** ハーフマラソンです。午前中の大半を費やす、走りごたえのある挑戦になります。

各種目のコース、スタート時刻、エントリーの詳細は、主催者がGarmin Run Asia Seriesの公式サイトで公開しています。本ガイドに公式情報以上の内容はありませんので、コースマップや競技規則は公式サイトが情報源です。

## MTRで馬鞍山へ

馬鞍山の街は、MTR**屯馬線**（Tuen Ma Line）に沿って広がっています。エリア内の駅は大水坑（Tai Shui Hang）、恒安（Heng On）、馬鞍山（Ma On Shan）、烏溪沙（Wu Kai Sha）の4つで、烏溪沙が終点です。九龍方面からは、大圍（Tai Wai）で屯馬線に乗り換えるか、紅磡（Hung Hom）や鑽石山（Diamond Hill）から乗り換えなしで向かうのが一般的です。

馬鞍山駅はショッピングセンターの**新港城中心**（MOSTown）と直結しているので、待ち合わせの目印にも便利です。沙田からならタクシーでもすぐの距離です。ただし、香港のロードレースではレース当日の朝に交通規制が敷かれるのが当たり前なので、車より電車を頼りにする人が大半です。

## 12月下旬の天気

12月は、香港でもっとも乾燥して過ごしやすい月のひとつです。朝は寒いというより涼しい程度で、夏の蒸し暑さはすっかり消え、海沿いでは風が出ることもあります。この街で走るには、これ以上ないほどの好条件です。

ランナーがよく持参するものは次のとおりです。

- スタートまで羽織っておき、号砲の前に脱いで捨てるかしまっておける薄手の上着や古いシャツ
- サングラス（冬の低い太陽が水面に反射するため）
- 帰りのMTR用のオクトパスカード（八達通）。レース後に券売機の列に並ばずに済みます
- 市内へ戻る電車で着替えるための乾いた服

## 馬鞍山でのレース当日のマナー

このコースは、人々の暮らしのすぐそばを通ります。沿道に並ぶマンションには多くの住民が暮らしていて、遊歩道の近くでは犬の散歩をする人や太極拳をするお年寄りの姿もよく見かけます。ランナーは道を譲り合い、夜明け前のウォーミングアップでは大声を控えています。

香港のロードレースは、主に交通事情に合わせるため朝早くスタートし、始発のMTRはゼッケンをつけた人たちでいっぱいになります。駅のエスカレーターでは、たとえ朝5時でも右側に立ち、左側を歩くのが地元の揺るぎない習慣です。給水所で歩く場合は、後ろのランナーが走り続けられるよう脇へ寄ります。

沿道の応援で飛び交うのは「**ガーヤウ！」（加油**）という広東語のかけ声です。直訳すると「油を足せ」という意味で、ランナー同士でも声をかけ合います。レース当日の朝に覚える広東語をひとつだけ選ぶなら、迷わずこの言葉です。

## スタート前とゴール後の過ごし方

平坦な**馬鞍山海濱長廊**（Ma On Shan Promenade）は、吐露港の岸辺に沿って続いています。レース後のクールダウンにちょうどよい散歩道で、対岸には西貢（Sai Kung）の山々や、港の船湾（Plover Cove）側の景色が広がります。すぐ隣には沙田・大埔（Tai Po）方面へ延びる長いサイクリングロードがあり、自転車が行き交うので、歩行者側を歩くようにしましょう。

完走したランナーの多くは、朝食をとりに新港城中心や近くの団地へ向かいます。地元の茶餐廳（チャーチャンテン）なら、ミルクティーやマカロニスープ、厚切りトーストがすぐに出てきます。注文は、壁に貼られたセットメニューを指さすだけで大丈夫です。脚にまだ余力があれば、数駅先の**沙田**（Sha Tin）まで足をのばすのもおすすめです。香港文化博物館（Hong Kong Heritage Museum）や、川沿いの城門河（Shing Mun River）の遊歩道があります。

街のすぐ背後には馬鞍山郊野公園が広がり、山頂へ向かうトレイルも延びています。とはいえ、山歩きは別の日の楽しみにとっておきましょう。ハーフマラソンを走り終えたあとなら、港沿いの散歩だけで十分です。
