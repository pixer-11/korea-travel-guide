## 吐露港畔的12月星期日

马鞍山和明信片上的香港截然不同。吐露港西岸，一排排高耸的住宅楼整齐林立，楼群背后是马鞍山光秃秃的青绿山脊。Garmin Run 亚洲系列赛的香港站路跑赛就设在这里，比赛日期为2026年12月20日（星期日），设3公里、10公里和21公里三个组别。

Garmin Run 亚洲系列赛在亚洲多个城市设有分站，香港站是其中之一。赛事没有选在坡陡车多的市中心，而是放在这片地势平坦的滨水社区。在九龙的人行道上跑过步的人，都会明白这个选择有多重要。

## 3公里、10公里还是21公里？

三个组别各有适合的人群：

- **3公里**：距离短，适合家庭、跑步新手，以及不想专门训练也想拿块奖牌的人。
- **10公里**：常跑步的人最常选的组别，适合想轻松跑出好成绩的跑者。
- **21公里**：即半程马拉松，是一次实打实的考验，大半个上午都要花在赛道上。

各组别的路线、起跑时间和报名信息由主办方在 Garmin Run 亚洲系列赛官网公布。本文不作任何补充，赛道图和比赛规则一律以官网为准。

## 搭港铁去马鞍山

港铁**屯马线**贯穿整个马鞍山区，沿线设有大水坑、恒安、马鞍山和乌溪沙四站，乌溪沙是全线终点站。从九龙出发的跑者一般在大围换乘屯马线，或从红磡、钻石山直接上车。

马鞍山站与**新港城中心**（MOSTown）商场相连，是约人碰头的好地标。从沙田打车过来也只要一小段路。不过香港路跑赛的比赛日早上照例都要封路，所以多数人宁愿坐港铁也不开车。

## 12月下旬的天气

12月是香港最干燥、最温和的月份之一。清晨只是微凉，并不寒冷，夏天的潮湿闷热早已散去，海滨一带常有微风。在这座城市里，很难找到比这更适合跑步的天气了。

跑者通常会带上这些东西：

- 一件薄外套或旧上衣，起跑前穿着保暖，鸣枪前脱掉丢弃或收好
- 一副墨镜，冬天太阳角度低，水面反光刺眼
- 一张八达通，赛后坐港铁回家不必在售票机前排队
- 一套干爽的换洗衣服，坐车回市区时换上

## 马鞍山比赛日早晨的礼仪

这条赛道就在居民的家门口。沿途的高楼里住满了人家，长廊附近难免会遇到遛狗的街坊和打太极的老人家。跑者会给他们让出空间，天亮前热身时也尽量压低嗓门。

香港的路跑赛大多一早开跑，主要是为了避开交通高峰，所以头几班港铁里挤满了别着号码布的人。在车站搭扶梯时，本地人习惯靠右站立、左侧通行，哪怕凌晨5点也不例外。在补给站改走路的人会靠边，好让后面的跑者继续往前跑。

沿途的观众会大喊“**加油！**”，这是粤语里的打气口号，字面意思是“添油”。跑者之间也会互相喊。比赛日早上要是只会说一句粤语，就学这一句吧。

## 起跑前与冲线后

平坦的**马鞍山海滨长廊**沿吐露港岸边延伸。赛后在这里慢慢走一段，正好放松身体，还能隔海眺望西贡的群山和对岸船湾一带。长廊旁有一条长长的单车径，一路通往沙田和大埔，骑车的人很多，步行时记得走行人一侧。

完赛的跑者大多去新港城中心或附近的屋苑吃早餐。本地茶餐厅出餐快，奶茶、通粉和厚多士随点随上，指着墙上的套餐牌就能点单。要是腿脚还有余力，可以坐几站到**沙田**，那里有香港文化博物馆和城门河畔的长廊。

马鞍山郊野公园就在社区背后的山上，有山径一路通往马鞍山山顶。不过这些还是留到改天再去吧——跑完半程马拉松，沿着海边走走就足够了。
