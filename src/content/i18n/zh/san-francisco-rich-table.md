## 为什么选择 Rich Table

还没看到菜单，你就先闻到了味道：黄油煎炒的香气，还有从沿墙而设、如同舞台般的开放式厨房飘来的一丝焦香。Rich Table 坐落在高夫街（Gough Street）上，位于海斯谷（Hayes Valley）南端边缘，餐厅内部由回收的谷仓木材搭建而成——墙壁和天花板上是浅色、带有节疤的木板，让这个空间感觉更像是一个改造过的干草阁楼，而不是身处旧金山繁华街区中的一家餐厅。铜锅悬挂在出菜口触手可及的地方。服务员穿梭于紧凑排列的餐桌之间的狭窄过道中，如果你坐在面对厨师的吧台位置，就能近距离观赏那些已成为当地小小传奇的菜品摆盘——充满创意的小份菜肴，以及一道会根据当周农夫市集食材变化的常换意面。这是一种在保持精湛技艺的同时又不失趣味的现代加州料理，凭借着上千条评价中始终保持的高分好评，赢得了一批忠实拥趸。

## 如何前往

Rich Table 位于高夫街 199 号（199 Gough St），正好处在海斯谷与西增区（Western Addition）边缘交界处，距离阿拉莫广场（Alamo Square）华丽的维多利亚式山墙和帕特里夏绿地（Patricia's Green）宽阔的草坪只有几个街区。如果你乘坐 BART 或 Muni 地铁，可在市政中心站（Civic Center station）下车，沿高夫街往西北方向步行约12-15分钟，或者搭乘21路海斯（21-Hayes）公交车，车站距离餐厅仅一个街区。海斯谷大部分晚上街边停车位都很紧张，建议预留额外时间绕圈找车位，或者停在附近的车库步行前往——无论如何，这一带的精品店和酒吧都很适合饭前散步消遣。

## 用餐体验

菜单会随季节变化，但精神内核始终如一：每道菜都围绕单一蔬菜或海鲜食材构建，并在你的预期之外稍作创新变化。过去的招牌菜包括搭配酸爽风味来平衡浓郁口感的布拉塔奶酪（burrata）、以时令核果为基础打造的鸭肉料理，以及用轻盈而出人意料的手法处理巧克力、柑橘、坚果等熟悉风味的甜点。菜量设计适合几道菜一起分享，而非每人各点一份主菜，所以最好和愿意一起分享菜肴的同伴一起前来。价位在旧金山品鉴式晚餐中属于中高档——并非城中最贵的厨房，但要做好享受一顿正式晚餐而非简单快餐的准备。

## 何时前往

Rich Table 只供应晚餐——没有午餐服务，所以不要计划下午前往。如果你想要一个安静的用餐环境、不慌不忙的厨房节奏，工作日5点到6点、也就是刚开门的这段时间最为清静，此时下班人潮尚未涌入。周末则完全不同：整个5点到10点的营业时段都持续繁忙，周末晚上通常是最热闹的时候，餐厅和吧台都会座无虚席，等位时间也最长。如果你的时间安排比较灵活，工作日较早的用餐时段是最放松地体验这家餐厅、又不会感觉匆忙的最佳方式。

## 像当地人一样用餐

提前预订——这是一家知名的目的地餐厅，而非鲜为人知的小众发现，无预约排队的成功率并不稳定，尤其是在周末。预订通常会提前数周滚动开放；如果你心仪的那晚已被订满,可以关注是否有取消的空位,或者试着5点整准时到店询问吧台座位,这类座位有时周转会比卡座更快。着装建议为简约休闲风——干净的牛仔裤搭配有领衬衫即可，不需要穿外套。付款以刷卡为主流方式；小费遵循美国餐厅18%-20%的惯例标准,不过要注意有些旧金山餐厅会在账单中额外收取服务费或医疗附加费，所以在额外加小费前请先仔细看账单。新来的食客常犯的错误是把这里当成看戏前的快速晚餐——像这样的厨房有自己的节奏，所以请预留几个小时从容用餐，尤其是当你点了多道共享菜肴而非单人主菜时。
