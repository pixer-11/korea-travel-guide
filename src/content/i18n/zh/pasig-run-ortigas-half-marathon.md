## 奥尔蒂加斯东区的首场21公里赛

Run Ortigas的比赛日期为2026年11月15日，21公里赛道设在奥尔蒂加斯东区的街道上。主办方宣布，这是该区域史上第一场半程马拉松，同一天早上还安排了几个短距离组别。

奥尔蒂加斯东区是帕西格的一片综合功能区，紧挨C5公路与奥尔蒂加斯大道（Ortigas Avenue）的交会处，Tiendesitas市集综合体也坐落在这一带。区内道路宽阔，路面新铺，还有大片空地尚待开发，赛道因此有足够的空间铺展开来。

## 比赛清晨的环境

马尼拉的路跑都是摸黑起跑的。为了避开炎热，马尼拉大都会各地的主办方通常赶在日出前鸣枪，而21公里组在路上耗时最长，更需要抢在太阳升高之前多跑一段。

11月正值吕宋岛进入较凉爽干燥的月份，但湿度依旧不减，有些年份的晚季台风仍会波及这一地区。熟悉马尼拉气候的跑者通常会这样准备：

- 除了补给站的供应，自己也随身携带电解质补充品
- 戴上帽子或遮阳帽，因为半马的最后几公里很可能要在直射的阳光下完成
- 备好一件干爽的上衣和一双凉鞋，方便从终点区走回去

## 天亮前如何抵达奥尔蒂加斯东区

奥尔蒂加斯东区没有轨道交通站点。MRT-3奥尔蒂加斯站（Ortigas Station）位于EDSA大道上，处在奥尔蒂加斯商务区的另一头，从C5步行过去路程很远。遇到天亮前起跑的比赛，多数跑者会叫Grab或出租车，也有人跟跑团一起拼车。

这里举办比赛时，道路管制通常在鸣枪前就已开始。C5和奥尔蒂加斯大道沿线的进场路段会因送人下车的车辆而拥堵，所以司机往往在离起点还有一两个街区的地方就让跑者下车，剩下的路步行前往。来自马尼拉大都会以外的跑者，前一晚多半住在帕西格的奥尔蒂加斯中心（Ortigas Center）或Kapitolyo一带，在那个时段坐车过来都只需一小段路程。

## Run Ortigas比赛日的一般流程

菲律宾的路跑赛流程大同小异。报名在主办方网站在线完成，常用的付款方式是GCash和银行卡。每位跑者会领到一份参赛包，里面一般有号码布和一件背心，通常需在赛前几天到指定地点领取。

在这类比赛中，短距离组的参赛者大多是家庭和周边商务区的公司跑团，21公里组率先列队，氛围也更认真。比赛当天的一些惯例如下：

- **起跑分区**：跑者在起跑线按距离自行分区站好，21公里组先于短距离组鸣枪出发。
- **号码布位置**：号码布别在胸前显眼处，因为裁判和摄影师要靠它辨认跑者。
- **补给站**：志愿者会递出一杯杯水。跑者边跑边接过水杯，喝完丢进桌子后方不远处的垃圾桶，而不是扔在路上。
- **终点区**：一般先领奖牌，再排队领恢复补给，接着是各个跑团拍照留念。由于数千名跑者聚在一起时手机信号时好时坏，大家通常会事先约好碰头地点。

赛后，跑者通常会去Tiendesitas或奥尔蒂加斯东区周边的咖啡馆吃顿迟来的早餐，这样就能在C5白天的车流高峰到来之前离开。
