## Run Fun 的独特之处

过去十年间，河内的高端餐饮界悄然建立起了国际声誉，而名厨 Hoang Tung 正是其中最受热议的人物之一——先是凭借 T.U.N.G Dining，后来又推出了更具实验性的 Å by TUNG。Run Fun – The Eating Room 则是他刻意反其道而行之的新尝试：还是同一个厨艺头脑，却褪去了所有的正式感。这里不再是多道式套餐（tasting menu）配安静的用餐厅，而是用更热闹、更social的空间取代了白桌布——越南食材依旧被赋予 Tung 标志性的那种玩味、出人意料的处理方式，只是上菜节奏更快、氛围更随性。对于那些读过河内高端套餐热潮的报道、却不想为此耗费一整晚时间（或预算）的游客来说，这里是体验同一套厨艺理念的一个更亲民的入口。

## 用餐体验会是怎样

由于这是一家新近开业的餐厅，具体菜品和定价仍在随着菜单不断调整而变化，因此建议前往前直接查询当前的菜品供应和套餐选项，而不要依赖二手的菜单描述。不过，Tung 在他旗下各家餐厅中一贯坚持的风格是：聚焦越南本地食材与街头美食的基因，再用精致餐饮的技法重新演绎——预期看到的是熟悉的味道以出人意料的形式呈现，而非经典菜肴的直接复刻。像这样的"休闲用餐空间"（casual eating room）在分量和形式上往往更偏向拼盘分享，而非单人单道菜，因此结伴而行（两人或更多）能让你在一顿饭里尝到更丰富的菜品。

## 如何前往及注意事项

与 Tung 旗下其他餐厅一样，Run Fun 也位于河内——毕竟他的声誉正是牢牢扎根于首都河内，而非扩展到胡志明市或其他城市。考虑到河内的热门新店在开业头几个月里，营业时间、是否接受无预约到店（walk-in）以及预订系统都可能迅速调整，建议在前往前不久再次确认当前的营业时间、确切地址和预订流程——把任何旧的信息或点评仅当作参考起点，而非最终依据。如果你此行还计划前往 T.U.N.G Dining 或 Å by TUNG，Run Fun 会是一个很有意思的对照：同样的厨艺理念，但调成了工作日般的休闲版本。

## 适合什么样的旅行者

这里不适合追求安静浪漫套餐体验的食客——那是 Tung 另外两家餐厅的定位。Run Fun 更适合想要一顿令人难忘、略带戏剧感却又不失轻松的用餐体验的旅行者：对这座城市主厨驱动的餐饮场景感兴趣的独行食客、想要分享拼盘的小团体，或是想在非特殊场合、非高预算的工作日晚上，也能尝到高概念越南料理的人。这里也更适合带着几分好奇心前来的食客——不要期待原汁原味的河粉（pho）或烤肉米线（bun cha），而是要敞开心扉去接受那些对熟悉越南风味的全新演绎。

## 如何像本地人一样前往用餐

由于这是一家新开业、人气迅速攀升的餐厅，最清静的时段通常是营业刚开始的时候——刚开门营业或早点去吃晚餐，往往能避开随着社交媒体传播和河内美食圈关注而逐渐形成的用餐高峰。如果有预订系统可用，最好提前预订，而不要冒险在周五或周六晚上直接无预约到店；一旦被本地美食媒体和 Instagram 关注到，河内的热门餐厅很快就会一位难求。在这个档次的现代河内餐厅，支付方式大多以刷卡或日益普及的移动/二维码支付应用（如 MoMo）为主，不过随身带一些现金作为备用也不失为明智之举。在越南，给小费不像在北美那样是必须的，但如果服务令人满意，四舍五入凑个整数或留一点酌情小费会很受欢迎，在这类餐厅也越来越常见。游客在这类热门主厨餐厅最容易犯的错误，就是把它当成观光间隙的快餐——请预留充足的时间，多点几道菜分享而非各自单点，并向服务员询问有什么新品或时令菜式，因为像 Tung 这样的厨房通常会根据食材的新鲜程度不断更新菜品。可以自信地用英语点餐（这个档次的餐厅员工通常都能熟练接待国际游客），不过学几句"Xin chào"（你好）和"Cảm ơn"（谢谢）作为礼貌用语，也会让体验更加愉快。
