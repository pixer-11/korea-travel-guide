## Ignis Table 为何此刻备受瞩目

上海的精致餐饮版图向来风云变幻，而这一季，厨师和美食作者们口中反复提到的名字，正是 Ignis Table。这是主厨徐嘉逸（Julien Xu）的最新项目，他的履历中包括在这座城市两家最受热议的品鉴菜单餐厅——Ultraviolet 和 Rêver——的历练。这样的背景在这里格外关键：这不是一位厨师试水的新尝试，而是一个多年来始终站在现代中餐可能性最前沿的人，如今终于开始经营自己的餐厅。

## 这里到底吃什么

厨房只围绕一套固定菜单展开，选用高级海鲜为主料，呈现方式带着现代中式的审美，而非套用欧式品鉴菜单的模板。可以期待的是那种层层推进、按道呈现的节奏——一枚扇贝、一片鱼肉、一碗贝类高汤，都足以撑起一整道菜的分量。由于是固定菜单形式，用餐者需要信任主厨的编排顺序，而不是自己点菜。

这正是真正意义上主厨餐桌的魅力所在：整个空间的设计围绕着"观看烹饪过程"本身，而不仅仅是品尝成品。这里通常设有开放式厨房或围绕料理台的座位，出餐口近在眼前，煎烤的瞬间、酱汁被舀起淋上的动作，甚至上桌前最后点缀的一片香草，都能被实时看到。

## 具体位置在哪里

Ignis Table 坐落在中华大厦（Zhonghua Mansion）内，这栋历史建筑如今已成为上海市中心一处颇具规模的垂直美食目的地，多家高水准餐厅与酒吧层层叠叠汇聚于同一栋楼中。这意味着来这里用餐不必只是单纯的一站式行程，完全可以把它当作一整晚活动的核心：提前到达，先在楼内其他地方喝一杯，再上楼享用品鉴菜单。

由于刚开业不久，随着大厦内商户名单逐渐稳定，具体楼层和入口信息也可能随之调整。预订时请直接确认具体房号或楼层，而不要只以大厦的主入口作为目标。

## 预订须知与到店当晚会经历什么

以这样的价位和形式，Ignis Table 完全依靠预订运营，不接待临时到店的客人。按人头计价的套餐、围绕主厨餐桌打造的空间，意味着每一轮开台的座位数量都十分有限——如果条件允许，建议提前几周预订，周末则需要更早安排。

- 敲定行程前，请直接向餐厅确认当前的营业日期和开台时间
- 预订时询问价格是否已包含服务费或酒水搭配
- 提前告知任何饮食禁忌，因为以海鲜为主料的固定套餐很难现场调整
- 为整套品鉴菜单的用餐过程预留至少两到两个半小时

## 像本地人一样赴约

上海的老饕们把主厨餐桌的预订看作一份实实在在的承诺，而不是可以随意变动的占位——如果计划有变，请务必提前留出足够时间取消，因为座位真的十分有限，很可能有其他人正在等位。

支付方式几乎清一色使用手机支付——微信支付或支付宝——而非现金，这个价位的套餐通常已经把服务费计入价格之中，所以预订时不妨顺便问一句，是否还需要额外给小费。

着装建议比日常休闲稍微正式一些，毕竟像中华大厦这样的场所里，主厨餐桌体验往往会吸引打扮得体的客群。到店时间以准时为佳，不宜过早也不宜迟到——品鉴菜单是按道次逐步推进的，任何一位客人的迟到都会打乱整个料理台的节奏。

初次到访的人常犯的错误，是抱着可以随意点单的期待前来。正确的心态应该是：准备好接受厨房端上的一切，按照它设定的顺序享用，把这份菜单的编排本身当作用餐体验的核心，而不是某种限制。

考虑到 Ignis Table 开业时间尚短，营业时间、具体的座位安排，甚至套餐内容本身，都可能在开业初期几个月内有所调整。这里提供的信息只是一个起点，在为这顿晚餐做具体安排之前，请直接向餐厅重新确认营业时间、价格，以及在中华大厦内的具体位置等细节。
