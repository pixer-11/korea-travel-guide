## 为什么 Ignis Table 这个时候特别值得关注

上海的高端餐饮圈从不缺新话题，而这一季，厨师和美食作者们反复提到的名字就是 Ignis Table。这是主厨徐嘉柱（Julien Xu）的最新项目，他的履历中包括在 Ultraviolet 和 Rêver 这两家上海最受关注的品鉴菜单餐厅任职的经历。这份背景在这里意义重大——这不是一位厨师在试水一个想法，而是一个在现代中餐边界上摸爬滚打多年的人，如今终于拥有了属于自己的餐厅。

## 这里到底吃什么

厨房只提供一份固定菜单，目前定价为每人 ¥1,880，以顶级海鲜为核心食材，呈现方式偏向现代中式感觉，而非欧式品鉴菜单的套路。可以期待那种精心编排、逐道推进的节奏——一颗带子、一片鱼、一碗贝类高汤，都能撑起一整道菜的分量。因为是固定菜单形式，你需要信任的是主厨的上菜顺序，而不是自己挑选菜品。

这正是真正意义上的主厨餐桌的魅力所在：整个空间的设计目的，是让你观看烹饪的过程，而不只是品尝成品。可以预期开放式厨房或吧台式座位，出餐台近到能让你实时看到摆盘的全过程——煎制的瞬间、酱汁被舀起的动作，以及最后一片香草放上盘子、菜品端走前的那一刻。

## 具体位置在哪里

Ignis Table 位于中华大厦（Zhonghua Mansion）内，这是一栋历史建筑，如今已成为上海市中心一处颇具代表性的垂直美食地标，一栋楼里叠加了多家水准不俗的餐厅和酒吧。这意味着，来这里用餐完全可以当作一整晚行程的主线，而不只是单独的一站——不妨提前到达，先在楼内其他地方喝一杯，再上楼享用品鉴菜单。

由于餐厅刚刚开业，具体楼层和入口信息可能会随着大厦租户名单的最终确定而有所调整。订位时请务必确认具体的楼层或单元号，而不要只是奔着大厦主入口而去。

## 订位须知与用餐当晚的注意事项

以这样的价位和形式，Ignis Table 完全依赖预约运作，几乎不接受临时到店的客人。每人 ¥1,880 的固定菜单，加上以主厨餐桌为核心设计的空间，意味着每个时段能接待的座位数量非常有限——如果可以，建议提前几周订位，如果是周末，则需要预留更长的提前量。

- 出发前请直接向餐厅确认当前的营业日和用餐时段
- 订位时询问价格是否已包含服务费或酒水搭配
- 提前告知任何饮食禁忌——固定菜单以海鲜为核心，临场调整的空间很小
- 完整的品鉴菜单用餐请预留至少两到两个半小时

## 像本地人一样赴约

上海食客对待主厨餐桌的订位，向来当作一项实实在在的承诺，而不是随时可以放弃的占位——如果计划有变，请提前充分取消，因为座位确实有限，很可能有其他客人正在等位。

支付方式几乎都是移动支付——微信支付或支付宝，很少使用现金；这个价位的固定菜单通常已经包含服务费，订位时不妨问清楚，是否还需要额外给小费。

着装建议略微正式一些；在中华大厦这样的场所体验主厨餐桌，通常会遇到打扮得体的其他客人。到达时间以准时为宜，不要提前太多，也不要迟到——品鉴菜单是按道逐一推进的，迟到会打乱吧台上所有客人的用餐节奏。

新客人最容易犯的错误，是抱着点单自由搭配的心态来订位。正确的心态应该是：准备好吃厨房端上来的每一道菜，按照厨师安排的顺序享用，把这个上菜顺序本身当作用餐的亮点，而不是一种限制。

考虑到 Ignis Table 才刚开业不久，营业时间、具体座位安排，乃至固定菜单的内容，在开业头几个月里都可能发生变化。请把本文的信息当作一个起点，出发前务必直接向餐厅重新确认具体细节——营业时间、价格，以及在中华大厦内的具体位置。
