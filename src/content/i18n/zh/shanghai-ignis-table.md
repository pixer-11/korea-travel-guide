## 为什么 Ignis Table 眼下这么值得关注

上海的精致餐饮圈向来风云变幻，而这一季，无论是主厨还是美食撰稿人，都在反复提到同一个名字：Ignis Table。这是主厨徐俊仁（Julien Xu）的最新作品，他的履历中有两段格外亮眼的经历——分别在城中话题度最高的两家品鉴菜单餐厅 Ultraviolet 和 Rêver 掌勺。这份背景在这里意义重大。这不是某位厨师初试啼声的小实验，而是一位多年深耕现代中式料理边界的厨师，如今终于拥有了自己的舞台。

## 这里究竟吃什么

后厨围绕一份固定菜单展开，选材以顶级海鲜为主，呈现方式带着现代中式的思路，而非欧式品鉴菜单的套路。可以期待那种一道接一道精心编排的节奏，让一颗扇贝、一片鱼肉、或是一碗贝类高汤，独自撑起整盘菜的分量。因为是固定菜单，你要做的不是自己挑菜，而是把选择权交给主厨的编排逻辑。

这正是真正的厨师餐台的魅力所在：整个空间的设计，重点不只是让你吃到成品，更是让你亲眼见证烹饪的全过程。餐厅多采用开放式厨房或吧台式座位，出餐台近在眼前，煎制的瞬间、酱汁淋下的动作、最后一片香草摆上盘的细节，你都能实时看见。

## 具体位置在哪

Ignis Table 位于中华大厦（Zhonghua Mansion）内，这栋历史建筑如今已成为上海市中心一座名副其实的"垂直美食地标"，一栋楼里叠加了多家颇具分量的餐厅与酒吧。这意味着来这里用餐，完全可以当作一整晚行程的核心，而不只是单一的一站。不妨提前到达，先在楼内其他地方喝上一杯，再上楼享用品鉴菜单。

由于开业时间尚短，具体楼层与入口信息可能随着大厦租户格局的调整而变化。预订时务必确认具体楼层或房间号，而不要只是奔着大厦的正门去找。

## 预订与用餐当晚须知

以这样的价位和形式来说，Ignis Table 完全依赖预订，几乎不接受临时到店。人均定价的固定菜单，加上厨师餐台的空间设计，意味着每一轮开台的座位数都非常有限。条件允许的话，建议提前几周预订，周末则要预留更长时间。

- 最终确定行程前，直接向餐厅确认当前的营业日期和开台时间
- 预订时问清价格是否已包含服务费或酒水搭配
- 提前告知任何饮食禁忌。这份以海鲜为核心的单一菜单，很难在现场临时调整
- 为一整轮品鉴菜单预留至少两到两个半小时

## 像本地人一样赴约

在上海，厨师餐台的预订被本地食客视为一种郑重承诺，而非可以随意更改的占位。如果计划有变，务必提前充分通知取消，因为座位确实有限，很可能有别的客人正在候位。

支付几乎全部通过手机完成，微信支付或支付宝为主，现金反而少见。这个价位的固定菜单往往已经把服务费算进定价，所以预订时最好问清楚，是否还需要额外给小费。

着装建议比日常休闲更讲究一些；像中华大厦这样的场所里，厨师餐台的客人普遍打扮得体。到达时间要准时，不要早也不要晚，因为品鉴菜单是按上菜节奏一道道推进的，迟到会打乱吧台上所有人的用餐节奏。

初次光顾的人常犯的错误，是带着点单式餐厅的期待来预订。正确的心态是：准备好吃下厨房呈上的每一道菜，按照后厨设定的顺序来，把这份编排本身当作用餐的乐趣所在，而不是一种限制。

考虑到 Ignis Table 开业时间尚短，营业时间、具体座位安排，甚至菜单内容本身，在最初几个月里都可能有所调整。请把本文当作了解这家餐厅的起点，规划当晚行程前，务必直接向餐厅重新确认营业时间、价格，以及在中华大厦内的具体位置等细节。
