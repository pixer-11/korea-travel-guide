## 为什么 Ignis Table 现在这么受关注

上海的高端餐饮圈从不缺新鲜话题，而这个季度厨师和美食作者们口中反复提到的名字，正是 Ignis Table。这是主厨徐嘉伦（Julien Xu）的最新项目，他的履历上写着上海两家最受热议的品鉴菜单餐厅——Ultraviolet 和 Rêver。这样的背景分量十足：站在这里掌勺的，不是一个刚刚尝试想法的新人，而是一位在现代中餐边界上摸索多年、如今终于自立门户的厨师。

## 菜品到底是什么样的

厨房只围绕一份固定菜单展开，主打顶级海鲜，呈现方式带着现代中式的思路，而非套用欧式品鉴菜单的模板。一道菜往往由单一食材撑起全场——一枚扇贝、一片鱼肉、一碗贝类高汤，节奏一道接一道，编排感十足。既然是固定菜单，你要做的不是自己挑菜，而是把主控权交给厨师，信任他的上菜顺序。

这正是真正的主厨餐台的魅力所在：整个空间的设计初衷，就是让食客亲眼见证烹饪过程，而不只是吃到成品。这里多半采用开放式厨房或吧台式座位，出餐口近得能让你实时看清整套动作——煎制的瞬间、酱汁被舀起淋上的一刻、最后一片香草摆上盘子再端走之前的每个细节。

## 具体位置在哪里

Ignis Table 坐落在中华大厦（Zhonghua Mansion）内，这栋历史建筑如今已成为上海市中心一座颇具规模的垂直美食地标，一栋楼里集结了多家高水准餐厅和酒吧。这意味着，来这里吃饭完全可以当作一整晚行程的主轴：不妨提早到，先在楼里其他地方小酌一杯，再上楼享用品鉴菜单。

由于刚刚开业，具体楼层和入口信息可能会随着大厦租户名单的逐步稳定而调整。预订时最好直接确认具体楼层或单元，而不是只奔着大厦正门去。

## 预订须知与到店当晚会遇到什么

以这样的价位和形式，Ignis Table 完全依靠预订运作，临时上门基本行不通。每人¥1,880的固定菜单，配上主厨餐台的空间设计，意味着每场接待的座位数量有限——条件允许的话提前几周预订，周末则要预留更长时间。

- 出发前直接向餐厅确认当前的营业日期和用餐时段
- 预订时问清楚价格是否已包含服务费或酒水搭配
- 提前告知任何饮食禁忌——单一的海鲜品鉴菜单临场很难调整
- 整套品鉴菜单用餐至少预留两到两个半小时

## 像本地人一样赴约

上海的食客把主厨餐台的预订当作正式承诺，而不是随口占个位——如果计划有变，务必提前充分告知取消，因为座位确实有限，很可能另有食客在等位。

支付方式几乎清一色是移动支付——微信支付或支付宝，而非现金；这个价位的固定菜单通常已经把服务费算在内，预订时不妨顺便问一句，是否还需要额外付小费。

着装建议比休闲装稍微正式一些；像中华大厦这样的建筑里，主厨餐台的体验往往会吸引打扮讲究的客人。准时到达比早到或迟到都更合适——品鉴菜单按道上菜、节奏紧凑，迟到一人会打乱吧台上所有人的用餐节奏。

初次光顾的人常犯的错误，是以为能像点单式餐厅那样随意挑选菜品。正确的心态是：厨房端上什么就吃什么，按照厨房设定的顺序来，把这份上菜顺序本身当作用餐体验的核心，而不是一种限制。

考虑到 Ignis Table 刚刚开业不久，营业时间、具体座位安排乃至品鉴菜单的内容，在开业初期都可能有所调整。请把本文内容当作参考起点，出发前务必直接向餐厅重新确认营业时间、价格，以及在中华大厦内的具体位置等细节。
