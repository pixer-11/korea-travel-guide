本ポリシーでは、Wander Atlas(以下「本サイト」)が収集する情報とその利用方法について説明します。広告やアナリティクスを実施する前に内容をご確認いただき、実際に有効化するツールに合わせて詳細を更新してください。

## 収集する情報

本サイトは主に静的な出版物であり、アカウント作成は必要ありません。当サイトは訪問者から個人情報を意図的に収集することはありません。メールを送信いただいた場合、送信者が選んで送った情報を受け取ります。

## Cookie、アナリティクス、広告

有効化されている場合、本サイトはトラフィックを測定し関連広告を配信するために、Cookie や類似の技術を使用するアナリティクスおよび広告パートナー(例:Google Analytics や Google AdSense)を利用することがあります。これらの第三者は、それぞれのプライバシーポリシーに従って、IPアドレス、デバイスおよびブラウザの種類、閲覧したページなどの情報を収集する場合があります。Google による広告用 Cookie の利用については、Google の Privacy & Terms に記載されています。

Cookie はブラウザの設定で管理または無効化することができ、該当プロバイダーの広告設定を通じてパーソナライズ広告をオプトアウトすることも可能です。

## Pinterest API

Wander Atlas は Pinterest API を使用して、自社の記事のピンを自社の Pinterest ビジネスアカウントに公開しています。**Wander Atlas は Pinterest, Inc. による承認、提携、またはスポンサーを受けたものではありません。**

当サイトは、Pinterest の公式 OAuth フローを通じて、単一の Pinterest アカウント(当サイト自身のもの)のみを接続しています。訪問者に Pinterest の認証情報を求めることは一切なく、他の個人に属する Pinterest データを収集、保存、または処理することもありません。この接続から保持するのは、暗号化されたリフレッシュトークンと、当サイト自身が作成したボードおよびピンの識別子のみであり、これによりスケジュールされたジョブが公開を継続できます。

アカウントの接続を解除した場合、または Pinterest の設定から当サイトのアクセスを取り消された場合、保存されたトークンおよび Pinterest 由来の識別子は30日以内にシステムから削除され、スケジュールされたジョブは停止します。

当サイトは、Pinterest のコンテンツや Pinterest 由来のデータを第三者に販売、再販、ライセンス供与、再配布、またはその他の方法で提供することはなく、広告やプロファイリングに使用することもありません。
