本政策说明 Wander Atlas("本网站")收集哪些信息以及这些信息的使用方式。请在启用广告或分析工具之前仔细阅读本政策,并根据您实际启用的工具更新相关细节。

## 我们收集的信息

本网站主要是一个静态出版物,不要求您创建账户。我们不会有意收集访客的个人信息。如果您给我们发送电子邮件,我们会收到您选择发送的信息。

## Cookie、分析与广告

如果启用,本网站可能会使用分析和广告合作伙伴(例如 Google Analytics 和 Google AdSense),这些合作伙伴会设置 Cookie 或使用类似技术来衡量流量并投放相关广告。这些第三方可能会根据其自身的隐私政策收集诸如您的 IP 地址、设备和浏览器类型以及浏览页面等信息。Google 使用广告 Cookie 的相关说明载于 Google 的隐私权与条款页面。

您可以通过浏览器设置来控制或禁用 Cookie,也可以通过相关服务提供商的广告设置选择退出个性化广告。

## Pinterest API

Wander Atlas 使用 Pinterest API 将我们自己撰写的文章发布为 Pin 图至我们自己的 Pinterest 商业账户。**Wander Atlas 未获得 Pinterest, Inc. 的认可、隶属关系或赞助。**

我们通过 Pinterest 官方的 OAuth 流程仅连接一个 Pinterest 账户——即我们自己的账户。我们绝不会向访客索取 Pinterest 登录凭据,也不会收集、存储或处理任何其他人的 Pinterest 数据。通过该连接,我们仅保留一个加密的刷新令牌(refresh token),以及我们自己创建的图板(board)和 Pin 图的标识符,这些信息用于让定时任务能够持续发布内容。

如果我们断开该账户连接,或者您通过 Pinterest 设置撤销我们的访问权限,我们会在 30 天内从系统中删除已存储的令牌以及任何源自 Pinterest 的标识符,定时任务也会随之停止。

我们不会出售、转售、许可、再分发或以其他方式向任何第三方提供 Pinterest 内容或源自 Pinterest 的数据,也不会将其用于广告投放或用户画像分析。

## 您的权利(GDPR / CCPA)

根据您所在地区的不同,您可能有权访问、更正或删除我们持有的关于您的个人数据,或反对某些形式的数据处理。如需提出请求,请通过下方地址与我们联系。

## 儿童

本网站不面向 13 岁以下儿童,我们也不会在明知情况下收集他们的个人信息。

我们可能会不时更新本政策;上方的"最后更新"日期反映了最新的修订情况。
