本政策说明 Wander Atlas（“本网站”，由其编辑 Pixer 运营的独立旅行刊物）收集哪些信息、由哪些服务处理这些信息，以及您可以做出的选择。

## 我们收集的信息

您无需创建账户即可阅读本网站。我们仅在以下情况下收集个人信息：

- **新闻通讯。** 如果您订阅，我们会收集您的电子邮箱地址以及您选择的偏好设置（您的语言和您希望了解的地区）。该名单由我们的邮件服务提供商 [MailerLite](https://www.mailerlite.com/legal/privacy-policy) 存储和发送，仅用于发送您所要求的新闻通讯。您可以随时通过每封邮件中的链接取消订阅或更改您的偏好设置。
- **发送给我们的邮件。** 如果您给我们写信，我们会收到您选择发送的信息，并仅将其用于回复您。
- **服务器日志。** 与任何网站一样，我们的托管服务提供商会自动处理诸如 IP 地址、浏览器类型和所请求页面等技术数据，以便提供页面并保护本网站免受滥用。

我们不会出售或出租您的个人信息。

## 数据分析

我们使用 [Plausible Analytics](https://plausible.io/privacy-focused-web-analytics) 来衡量流量，这是一款注重隐私保护的工具，不使用 Cookie，也不收集个人数据。它只为我们提供汇总统计数据（例如，有多少人访问了某个页面，以及他们来自哪个国家或网站）。

## 存储在您设备上的信息

某些功能会在您自己的浏览器中保存少量信息（本地存储），例如您保存到“我的行程”中的地点，以及您是否已经关闭过新闻通讯提示。这些信息保留在您的设备上，不会发送给我们，您可以随时从浏览器设置中清除这些信息。

## 联属链接与合作伙伴服务

本网站上的部分链接是通往旅行服务的联属链接（例如 Klook，以及 Travelpayouts 网络的合作伙伴，如 Aviasales、Kiwitaxi、Localrent 和 Yesim）。如果您点击此类链接并完成预订，我们可能会赚取佣金，且不会给您带来额外费用。这些链接会被标注出来，并且它们绝不会影响我们的写作内容。

当您点击联属链接，或使用某些页面上显示的合作伙伴搜索小工具（例如航班搜索）时，该合作伙伴可能会设置 Cookie 或收集信息，以追踪引荐来源并提供其服务。此类处理受该合作伙伴自身隐私政策的约束。

## 广告

本网站目前不展示广告。如果我们开始展示广告，例如通过 Google AdSense，以下内容将适用：

- 包括 Google 在内的第三方供应商会使用 Cookie，根据您之前对本网站或其他网站的访问情况来投放广告。
- Google 使用广告 Cookie 使其及其合作伙伴能够根据您对本网站和/或互联网上其他网站的访问情况向您投放广告。您可以在[Google 如何使用来自使用其服务的网站或应用的信息](https://policies.google.com/technologies/partner-sites)中了解更多信息。
- 您可以访问 [Google 广告设置](https://adssettings.google.com) 来选择退出个性化广告。您也可以在 [www.aboutads.info](https://www.aboutads.info/choices/)，或者在欧洲地区通过 [www.youronlinechoices.eu](https://www.youronlinechoices.eu/) 选择退出部分第三方供应商出于个性化广告目的使用 Cookie。
- 欧洲经济区、英国和瑞士的访客在使用此类 Cookie 之前，将通过同意工具被要求给予同意。

我们将在广告启用后更新本政策。

## Pinterest API

Wander Atlas 使用 Pinterest API 将我们自己文章的 Pin 发布到我们自己的 Pinterest 商业账户上。**Wander Atlas 未获得 Pinterest, Inc. 的认可，也与其没有关联或赞助关系。**

我们通过 Pinterest 官方的 OAuth 流程仅连接一个 Pinterest 账户——即我们自己的账户。我们绝不会向访客索取 Pinterest 登录凭据，也不会收集、存储或处理属于任何其他人的 Pinterest 数据。通过该连接，我们仅保留一个加密的刷新令牌，以及我们自己创建的展板和 Pin 的标识符，这些信息使得定时任务能够持续发布内容。

如果我们断开该账户连接——或者您从自己的 Pinterest 设置中撤销我们的访问权限——我们会在 30 天内从我们的系统中删除所存储的令牌以及任何源自 Pinterest 的标识符，定时任务也会随之停止。

我们不会出售、转售、许可、再分发 Pinterest 内容或源自 Pinterest 的数据给任何第三方，也不会将其用于广告或用户画像分析。

## 我们保留数据的时长

当您取消订阅后，我们会立即停止向您发送邮件。此后，您的邮箱地址仍会保留在我们邮件服务提供商的名单中，并标记为“已取消订阅”，这样可以防止误发邮件给您。如果您希望彻底删除该地址，请给我们发送邮件，我们会将其删除。您发送给我们的邮件会保留至回复所需的时长。分析数据均为汇总数据，不包含任何个人数据。

## 您的选择（GDPR / CCPA）

根据您所在的地区，您可能有权访问、更正或删除我们持有的关于您的个人数据，可以反对或限制某些处理活动，并可以随时撤回同意。我们不出售个人信息。如需提出请求，请通过下方地址与我们联系。

## 儿童

本网站并非面向 13 岁以下儿童，我们也不会在知情的情况下收集他们的个人信息。

## 变更

我们可能会不时更新本政策；上方的“最后更新”日期反映了最新的修订情况。
