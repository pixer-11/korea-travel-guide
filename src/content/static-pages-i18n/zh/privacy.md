本政策说明 Wander Atlas（“本网站”，由其编辑 Pixer 运营的独立旅行出版物）收集哪些信息、哪些服务会处理这些信息，以及您拥有哪些选择。

## 我们收集的信息

您无需创建账户即可阅读本网站。我们仅在以下情况下收集个人信息：

- **新闻通讯。** 如果您订阅，我们会收集您的电子邮箱地址以及您选择的偏好（您的语言和您想了解的地区）。该名单由我们的邮件服务提供商 [MailerLite](https://www.mailerlite.com/legal/privacy-policy) 存储和发送，仅用于发送您所要求的新闻通讯。您可以随时通过每封邮件中的链接取消订阅或更改偏好设置。
- **发给我们的邮件。** 如果您给我们写信，我们会收到您选择发送的信息，并仅用于回复。
- **服务器日志。** 与任何网站一样，我们的托管服务提供商会自动处理技术数据，例如 IP 地址、浏览器类型和请求的页面，以传送页面并保护本网站免遭滥用。

我们不会出售或出租您的个人信息。

## 分析统计

我们使用 [Plausible Analytics](https://plausible.io/privacy-focused-web-analytics) 来衡量流量，这是一款注重隐私的工具，不使用 Cookie，也不收集个人数据。它仅为我们提供汇总统计数据（例如，某个页面的访问人数以及访客来自哪个国家或网站）。

## 存储在您设备上的信息

某些功能会在您自己的浏览器中（本地存储）保存一些小信息，例如您保存到“我的旅程”的地点，以及您是否已经关闭新闻通讯提示。这些信息保留在您的设备上，不会发送给我们，并可随时通过浏览器设置清除。

## 联盟链接与合作服务

本网站上的一些链接是指向旅行服务的联盟链接（例如 Klook 以及 Travelpayouts 网络的合作伙伴，如 Aviasales、Kiwitaxi、Localrent 和 Yesim）。如果您点击其中一个链接并完成预订，我们可能会赚取佣金，而您不会因此支付额外费用。这些链接均已标明，且它们绝不会影响我们的写作内容。

当您点击联盟链接，或使用某些页面上显示的合作伙伴搜索小工具（例如航班搜索）时，该合作伙伴可能会设置 Cookie 或收集信息以追踪推荐来源并提供其服务。此类处理受该合作伙伴自身隐私政策的约束。

## 广告

本网站目前不展示广告。如果我们开始展示广告，例如通过 Google AdSense，则以下内容将适用：

- 包括 Google 在内的第三方供应商会使用 Cookie，根据您先前对本网站或其他网站的访问情况来投放广告。
- Google 使用广告 Cookie 使其及其合作伙伴能够根据您对本网站和/或互联网上其他网站的访问情况向您投放广告。您可以在 [Google 如何使用来自使用其服务的网站或应用的信息](https://policies.google.com/technologies/partner-sites) 中了解更多信息。
- 您可以访问 [Google 广告设置](https://adssettings.google.com) 以选择退出个性化广告。您也可以在 [www.aboutads.info](https://www.aboutads.info/choices/)，或在欧洲通过 [www.youronlinechoices.eu](https://www.youronlinechoices.eu/)，选择退出部分第三方供应商出于个性化广告目的使用 Cookie 的行为。
- 欧洲经济区、英国和瑞士的访客在使用此类 Cookie 之前，将通过同意工具被要求提供同意。

我们将在开启广告时更新本政策。

## Pinterest API

Wander Atlas 使用 Pinterest API 将我们自己文章的 Pin 发布到我们自己的 Pinterest 商业账户。**Wander Atlas 未获得 Pinterest, Inc. 的认可、与其无关联、亦非其赞助。**

我们通过 Pinterest 的官方 OAuth 流程连接单一的 Pinterest 账户——即我们自己的账户。我们绝不会向访客索取 Pinterest 账户凭据，也不会收集、存储或处理属于任何其他人的 Pinterest 数据。通过该连接，我们仅保留加密的刷新令牌以及我们自己创建的看板和 Pin 的标识符，这使得定时任务能够持续发布内容。

如果我们断开该账户连接——或者您从您的 Pinterest 设置中撤销我们的访问权限——我们会在 30 天内从我们的系统中删除存储的令牌以及任何源自 Pinterest 的标识符，并且定时任务将停止运行。

我们不会出售、转售、许可、再分发或以其他方式向任何第三方提供 Pinterest 内容或源自 Pinterest 的数据，也不会将其用于广告或用户画像。

## 我们保留数据的时长

我们会保留您的新闻通讯电子邮箱地址，直至您取消订阅；您发送给我们的邮件，我们会保留至回复所需的时长。分析数据为汇总数据，不含任何个人数据。

## 您的选择（GDPR / CCPA）

根据您所在的地区，您可能拥有访问、更正或删除您的个人数据的权利，反对或限制某些处理行为的权利，以及随时撤回同意的权利。我们不出售个人信息。如需提出请求，请通过下方地址与我们联系。

## 儿童

本网站不面向 13 岁以下儿童，我们也不会在明知的情况下收集他们的个人信息。

## 变更

我们可能会不时更新本政策；上方的“最后更新”日期反映最新的修订情况。
